¿Cómo funciona?
Escribe un monto en euros o en dólares — el otro campo y los bolivianos se calculan solos. La calculadora compara paralelo vs. oficial y te dice cuál te conviene y cuántos BOB de más obtienes con esa opción, marcando la tarjeta ganadora con ⭐. El tipo de cambio oficial (TCO) se lee primero de apibcb.cucu.bo, una API independiente que republica en JSON el dato publicado por el BCB (sin depender de un proxy CORS de terceros que podría cachear datos viejos); si falla, se intenta leer directo del HTML de la página de última cotización de bcb.gob.bo vía proxy público, y si eso también falla, se usa bo.dolarapi.com. Nota: el BCB publica el TCO una sola vez por día hábil (cerca de las 20:00, vigente al día siguiente), así que ninguna fuente puede mostrar cambios más rápido que eso. EUR/USD se lee de open.er-api.com. El paralelo se lee del precio "Vendés a" de Binance P2P (USDT/BOB) a través del endpoint específico de la API pública de criptoya.com — el mismo dato que ves en la tabla de criptoya.com/bo, con CORS habilitado y sin necesitar proxy; si esa API no responde, como respaldo se intenta leer el HTML de sitios de referencia a través de un proxy público, que puede fallar en cualquier momento. El chip EUR/USDT · Binance P2P muestra el mejor precio (el más bajo) al que se está comprando USDT con euros en Binance P2P, filtrando solo anuncios que aceptan Wise o Banco Santander y que no exigen tener BTC para poder operar con el anunciante. Ese filtrado lo hace el bot de Telegram (que corre server-side vía GitHub Actions cada 15 minutos, sin necesitar proxy porque no es un navegador) y lo deja guardado en el repo; esta página lo lee directo de ahí, mismo origen, sin proxy. Si ese dato no está disponible o quedó viejo, como respaldo se intenta la misma consulta directo desde el navegador vía un proxy CORS público (puede fallar), y si eso también falla, se usa el precio general de criptoya.com, SIN esos filtros — el chip avisa si eso pasa. Si tienes un monto en euros cargado arriba, debajo del chip aparece a cuántos USDT equivale. Si alguno no se pudo leer, edítalo directamente en su casillero de arriba.
